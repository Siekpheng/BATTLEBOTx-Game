# [🤖 BATTLEBOTx — AI FARM Combat Robotics](https://siekpheng.github.io/BATTLEBOTx-Game/)

3D Combat Robotics Arena game with custom Autodesk Fusion CAD robot models, dynamic 60 FPS thermal engine, dual-controller support, local split-screen, and WebRTC 1v1 online multiplayer.

## 🚀 How to Run Locally

### Windows (1-Click)
Simply double-click either:
- **`play.bat`** or **`start_game.bat`**

This will automatically:
1. Detect Python and start the local game server.
2. Enable the native Windows gamepad bridge (for Xbox, PlayStation, and USB controllers).
3. Open `http://localhost:8080/index.html` in your default web browser.

### Manual Launch (Command Line)
```bash
python server.py
```
Then open `http://localhost:8080/index.html` in your browser.
